# Безопасность

Сервер принимает один аккаунт. Первая привязка требует проверенной подписи
Telegram и точного `OWNER_USERNAME`; затем проверяется закреплённый числовой ID.
Повторная проверка выполняется на каждом приватном запросе, включая историю,
файлы, push и восстановление cookie-сессии. Существование старой сессии или другой
записи в базе идентичностей не даёт доступа.

Telegram OIDC проверяется по подписи, issuer, audience, сроку и nonce. Widget
проверяется HMAC всех подписанных полей, сроком и защитой от повторного применения.
Challenge одноразовый. Ключи запрашиваются по TLS с фиксированного Telegram endpoint;
допускается ограниченный по времени доверенный кеш.

Cookie `__Host-workspace-session`: Secure, HttpOnly, SameSite=Lax, Path=/.
В базе хранится хеш случайного идентификатора. Изменяющие запросы требуют точного
Origin и CSRF. Секрет сессии не передаётся JavaScript и не хранится в localStorage.
Ключ локальной службы отделён от браузерной авторизации и обладает доступом
к синхронизации. Секреты хранятся вне Git: локальные файлы с закрытыми правами,
Lockbox и закрытый серверный config; значения не выводятся в диагностику.

Загрузка файлов ограничена размером, именем, количеством и целевой задачей;
содержимое неизменяемо после завершения, SHA-256 перепроверяется на компьютере.
Вложения — внешние данные. Markdown очищается, удалённые tracking-изображения
не загружаются, приватные tool output и reasoning не экспортируются.

Исходные ограничения Codex сохраняются: рабочие корни, сеть, режим выполнения
и правила подтверждения опасных действий. Отсутствующие права не угадываются.
Неопределённая отправка не повторяется автоматически.

Push отправляется только закреплённому аккаунту и на проверенные push endpoints.
Непосредственно перед отправкой доступ проверяется снова. Название и начало
ответа могут быть видны на экране блокировки; уведомления включаются явно.
Сервис-воркер не кеширует приватные ответы API.

VM принимает SSH только с конкретного административного /32, приложение — от
сети Gateway. Локальный компьютер делает только исходящие HTTPS-запросы.
Настройки VPN, TLS и корпоративной безопасности приложение не изменяет.
